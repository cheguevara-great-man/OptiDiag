# SFF-8472 与 SFF-8690 实现覆盖清单

本文区分三件容易混淆的事：

1. **规范字段已实现**：软件能够按标准把字节解释为有名称、有单位的字段。
2. **厂商字段可见**：软件显示原始寄存器，但没有标准含义可供解释。
3. **真实硬件已验证**：需要指定 USB-I²C 适配器和真实模块才能完成，目前尚未进行。

## 1. 基础识别与 SFF-8024

| 区域 | 当前实现 |
|---|---|
| Identifier | SFF-8024 Rev 4.14 的 00h-26h 已分配值；保留和厂商范围分类 |
| Connector | 全部已分配连接器及保留/厂商范围分类 |
| Encoding | 00h-08h，包括 64B/66B、256B/257B、PAM4 |
| Extended Compliance | 00h-4Ch、7Fh-81h；其余值明确标为保留或未分配 |
| 传统兼容位 | Ethernet、SONET、Fibre Channel、InfiniBand 的 SFF-8472 位图 |

## 2. SFF-8472 A0h 与 A2h lower

| 功能 | 当前实现 |
|---|---|
| 厂商与产品信息 | 名称、OUI、PN、Rev、SN、日期、波长 |
| 链路参数 | 标称速率、上下容差、SMF/OM1-OM4 长度、铜缆衰减和长度乘数 |
| 能力声明 | Options、诊断类型、增强选项、速率选择、CDR、功耗等级 |
| 阈值 | 温度、电压、偏置、TX/RX 功率；可选激光器温度/TEC |
| 校准 | Internal Calibration；External Calibration 的斜率、偏移和 RX 四次多项式 |
| 实时监控 | 原始值、工程单位、mW/dBm |
| 状态/告警 | 110、112-119 的状态、软控制、Alarm/Warning 和均衡/加重 |
| 增强功能 | 56-74 的所有标准字段；保留位也原样标出 |
| 校验 | CC_BASE、CC_EXT、CC_DMI |

## 3. Page 02h

| 功能 | 当前实现 |
|---|---|
| RDT | 行为版本、当前值可读、手动/自动、signed 值和 `50% + value/256×100%` |
| RPM 状态 | 数据就绪、时钟/位/相位/帧锁定 |
| RPM 调试 | 最近 24-bit MSG、11-bit TOM |
| RPM 计数器 | LOL、Frame、TOM Error、MSG Error；大端 16/32 位 |
| RPM 控制 | 远端命令字节序、调制指数、TX/RX 状态与使能 |
| RPM 安全 | 发送组、TX 抑制、RX 写保护 |
| RPM 用户数据 | TX/RX 8 字节，HEX 与 ASCII |
| RPM 锁存状态 | 174-175 的全部标准告警位 |

## 4. Page 03h 高精度时延

软件先检查 Format ID，再选择对应布局：

- `CA1Bh`：光模块；解析压缩校准日期、OUI/OSI、Stratum、Lane/Mode。
- `100Bh`：回环模块；解析校准不确定度和三组路径时延。
- q8.16 的 24-bit 接收功率修正多项式。
- q8.8 的温度失谐系数。
- q16.16 的平均时延和最大偏差。
- 根据当前 RX 功率和温度计算修正后的接收时延与波长失谐。
- 校验 CC_CALIB，并对未知 Format/Version、Lane 数异常给出诊断。

## 5. RPM 远端第二模块

Page 20h-27h 全部按规范条件采集：

- 20h + 21h 重组为远端 A0h。
- 22h 作为远端 A2h lower。
- 23h 作为远端 Page 00h/01h。
- 24h 作为远端 Page 02h。
- 上述内容重新进入同一个 SFF-8472 解码流程，在界面“RPM 远端第二模块”中独立显示身份、监控和完整字段。
- 25h 在 SFF-8472 中是 Reserved；26h-27h 是 Vendor Specific，因此只显示原始数据和正确访问属性，不能虚构标准语义。

## 6. SFF-8690

SFF-8690 是叠加在 SFF-8472 Page 02h 上的可调谐扩展，不是独立替代协议。软件以 A0h byte 65 bit 6 自动检测，并解析：

- Tunability、自调谐、TX Dither、通道和波长选择能力。
- 首/末激光频率、signed 最小网格间隔和计算通道数。
- 通道号、波长设定值和通道推导频率。
- 自调谐/Dither 控制。
- 频率误差、波长误差。
- 当前自调谐、温控故障、波长失锁、TX 未就绪。
- 全部锁存状态和对应告警。

模拟数据源可手动勾选是否包含 SFF-8690；真实数据源将由声明位自动检测。

界面还提供“模拟 RPM 远端”开关。开启后会声明 RPM、采集 Page 20h-27h，并让“RPM 远端第二模块”页面立即出现一套独立的身份、监控和字段数据。

## 7. 尚需真实硬件完成的验证

标准字段的软件实现已经具备，但以下内容不能靠模拟器证明：

- 某一款 USB-I²C 适配器的驱动、最大分块、超时、NACK 和热插拔行为。
- 不同厂商对分页切换等待时间、清读锁存位和原子多字节写的实际要求。
- Address Change、RPM 空口时延及真实远端更新一致性。
- 厂商保留页、密码、解锁顺序和公司自定义协议。

接入真实硬件时需要：适配器准确型号/API 或 SDK、驱动安装包、接线说明，以及至少一份去敏的正常模块 Dump。最好再提供一份故障或告警状态 Dump，用于回归测试。
