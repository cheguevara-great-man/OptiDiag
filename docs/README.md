# OptiDiag 学习文档导航

这套文档不是 API 清单，而是一条从“完全不知道上位机是什么”走到“能自己增加协议和硬件适配器”的学习路线。建议按顺序阅读；遇到暂时不懂的术语先继续，不必第一次就记住所有寄存器。

1. [项目方案与阶段边界](00-项目方案与阶段边界.md)：软件解决什么问题，当前哪些功能是模拟的。
2. [上位机与 I²C 入门](01-上位机与I2C入门.md)：理解主机、从机、地址、寄存器、读写事务。
3. [从零学习与实战手册](10-从零学习与实战手册.md)：运行程序，完成读取、曲线、Dump、比较和安全写入练习。
4. [安全写入与故障处理](11-安全写入与故障处理.md)：在碰任何可写字节前必须阅读。

## 第二层：理解协议

6. [SFF-8472/SFF-8690 覆盖清单](06-SFF-8472与SFF-8690实现覆盖清单.md)：代码已经实现到哪里。
7. [CMIS 协议与实现导读](07-CMIS协议与实现导读.md)：Lower Memory、Page、Bank、Lane、VDM、CDB。
8. [CMIS 5.3 覆盖矩阵](08-CMIS-5.3覆盖矩阵.md)与 [CMIS 5.4 覆盖矩阵](09-CMIS-5.4覆盖矩阵.md)：版本差异和实现证据。

## 推荐练习顺序

| 练习 | 目标 | 数据源 | 是否写入 |
|---|---|---|---|
| 1 | 找到 Vendor Name 和温度 | 模拟 SFF-8472 | 否 |
| 2 | 开启周期读取并观察曲线 | 任意模拟器 | 否 |
| 3 | 保存两个 Dump 并比较 | 任意模拟器 | 否 |
| 4 | 切换 SFF-8690，观察自动检测证据 | 模拟 SFF-8472 | 否 |
| 5 | 对普通 RW 字段执行安全写入 | 模拟器 | 是 |
| 6 | 观察 Page/Bank 选择器被阻止 | 模拟 CMIS | 不会发送 |
| 7 | 执行无破坏性的 CMIS CDB 查询 | 模拟 CMIS 5.3/5.4 | 是，协议操作 |
| 8 | 增加一个只读解码字段和测试 | 源代码 | 否 |

## 三条学习原则

- 界面显示的“值”一定来自某个地址、位域和换算公式；学会沿 `SourceRegister` 反向追踪。
- 读操作也可能有副作用，例如 `ReadOnlyClearOnRead` 会清除锁存标志；“只读”不等于“完全无影响”。
- 真实模块以正式规范、厂商文档和实测 Dump 为准。模拟器用于学习与回归，不是硬件互操作性证明。
